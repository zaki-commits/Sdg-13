# SDG 13 (iklim)

SOLo karena tidak bersama grup


## 1. Tentang Proyek
Earth Need Us adalah platform website edukasi yang dibangun untuk memenuhi tugas UTS Pemrograman Web dengan mengangkat tema Aksi Iklim (SDG 13). Website ini dirancang agar masyarakat luas, terutama generasi muda, dapat lebih mudah memahami pentingnya menjaga kelestarian bumi dan mengambil tindakan nyata dari hal-hal kecil.

## 2. Fitur & Struktur Halaman
Website ini terdiri dari beberapa halaman utama yang saling terhubung:
- **Beranda (`index.html`):** Halaman sambutan utama yang dilengkapi dengan kartu navigasi interaktif menuju halaman lain.
- **Edukasi (`edukasi.html`):** Berisi wawasan seputar isu lingkungan, grafik tren kondisi hutan global, serta tabel perbandingan kesehatan bumi.
- **Aksi Nyata (`aksi-nyata.html`):** Halaman interaktif berisi daftar ceklis kebiasaan ramah lingkungan dan formulir pendaftaran relawan.
- **Artikel (`artikel.html`):** Kumpulan referensi bacaan dan tautan artikel eksternal terpercaya (seperti FAO, PBB, dan WWF).
- **Tentang (`tentang.html`):** Halaman profil yang menjelaskan latar belakang pembuatan website.

## 3. Teknologi yang Digunakan
- **HTML5:** Digunakan untuk menyusun struktur elemen semantik website.
- **CSS3 (Custom CSS):** Digunakan untuk mengatur desain visual, tata letak grid/flexbox, grafik batang, dan membuat tampilan responsif tanpa menggunakan *framework* eksternal.
- **GitHub & GitHub Pages:** Digunakan untuk penyimpanan kode (*repository*) dan mempublikasikan website secara online.
