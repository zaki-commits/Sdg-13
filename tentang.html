Tentang Proyek Ini

Website ini dibuat sendiri oleh Zaki Mubarak Ahmad sebagai tanggung jawab dari proyek pembelajaran web responsif dan edukasi lingkungan hidup yang dilakukan oleh kelompok SDG 13.

Website ini juga merupakan cadangan (*backup*) dari proyek Earth Need Us.

👥 Anggota Kelompok:

  • Zaki Mubarak Ahmad (Penanggung Jawab Beranda / index.html)

🛠️ Teknologi & Metode Pengembangan

Website ini dirancang secara orisinal menggunakan struktur teknologi web dasar tanpa kerangka (*framework*) eksternal:

  • HTML5: Penyusunan struktur dokumen web semantik.
  • CSS3 (Pure Custom CSS): Pengaturan tata letak responsif, skema warna alam, dan pembuatan grafik batang visual murni.
  • GitHub Pages: Media publikasi dan pengawasan versi kode secara online.
